## 1️⃣ 능동 부품 (Active Components)

### MCU 모듈

| 항목 | 내용 |
|:-----|:-----|
| **부품명** | ESP32-S3-WROOM-1-N16R8V |
| **제조사** | Espressif |
| **사양** | 240MHz Dual-Core, 16MB QIO Flash, 8MB OPI PSRAM |
| **통신** | WiFi 802.11 b/g/n + BLE 5.0 (내장) |
| **패키지** | Module 18×25.5mm |
| **수량** | 1 |
| **비고** | DevKitC-1 개발보드 사용 시 별도 구매 불필요 |

### 카메라 모듈

| 항목 | 내용 |
|:-----|:-----|
| **부품명** | OV3660 카메라 모듈 |
| **제조사** | OmniVision |
| **사양** | 3MP, UXGA(1600×1200), JPEG 출력 |
| **인터페이스** | DVP 8-bit 병렬 + SCCB(I2C) 제어 |
| **패키지** | 24pin FPC |
| **수량** | 1 |
| **대체부품** | OV2640 (2MP, 하위호환) |
| **비고** | XCLK 20MHz, JPEG Q10, 프레임버퍼 PSRAM 저장 |

### IMU 센서

| 항목 | 내용 |
|:-----|:-----|
| **부품명** | MPU-6050 |
| **제조사** | InvenSense (TDK) |
| **사양** | 6축 (3축 가속도 + 3축 자이로), ±4g, ±500°/s, DLPF 42Hz |
| **인터페이스** | I2C (주소: 0x68), Fast Mode 400kHz |
| **패키지** | QFN-24 (4×4mm) |
| **수량** | 1 |
| **대체부품** | ICM-20602 |
| **비고** | 반려동물 활동량 · 꼬리흔들기 · 수면 감지용 |

### 심박/산소포화도 센서

| 항목 | 내용 |
|:-----|:-----|
| **부품명** | MAX30102 |
| **제조사** | Maxim Integrated (Analog Devices) |
| **부품번호** | MAX30102EFD+ |
| **사양** | 광학 심박(HR) 및 SpO2 센서, IR LED 모드, 400 SPS |
| **인터페이스** | I2C (주소: 0x57), Fast Mode 400kHz |
| **패키지** | OLGA-14 (5.6×3.3mm) |
| **수량** | 1 |
| **대체부품** | MAX30101 |
| **비고** | 반려동물 심박수 · HRV 측정용 |

## 2️⃣ 수동 부품 (Passive Components)

> ⚠️ **주의**: 수동부품은 일반적인 회로 설계 기준으로 추정한 것입니다. 실제 회로도에 따라 달라질 수 있습니다.

| # | 부품명 | 값 | 패키지 | 수량 | 용도 |
|:-:|:-------|:---|:------:|:----:|:-----|
| 1 | 칩 저항 | 4.7kΩ | 0402 | 2 | I2C 풀업 (SDA: GPIO1, SCL: GPIO2) |
| 2 | MLCC 캡 | 100nF | 0402 | 6 | MCU(×4) + MPU6050(×1) + MAX30102(×1) 바이패스 |
| 3 | MLCC 캡 | 10µF | 0603 | 3 | MCU 벌크(×2) + LDO 입력(×1) |
| 4 | MLCC 캡 | 1µF | 0402 | 1 | MAX30102 LED 드라이버 전원 |
| 5 | MLCC 캡 | 22µF | 0805 | 1 | LDO 출력 안정화 |
